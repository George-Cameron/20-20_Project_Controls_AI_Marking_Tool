# Project Controls AI Powered Marking Companion

A web-based AI marking tool for learners on 20/20 Project Management's Project
Controls course. Learners upload their assignment, choose the module, and
receive a criteria-aligned mark sheet generated by Claude.

## Deploying to Render (free)

Render's free web service tier works well for this tool.

### One-click deploy (recommended)

1. Log in to the [Render Dashboard](https://dashboard.render.com).
2. Click **New → Blueprint**, then connect this GitHub repository.
3. Render detects `render.yaml` and sets up the service automatically.
4. When prompted, set the environment variable:
   - `ANTHROPIC_API_KEY` — your Anthropic API key (starts with `sk-ant-...`)
5. Click **Apply**.

The first build takes ~2 minutes. After that, every `git push` to the branch
Render is watching will redeploy automatically.

### Manual setup (if you'd rather not use the blueprint)

1. In the Render Dashboard, click **New → Web Service** and connect this repo.
2. Configure:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** Free
3. Under **Environment**, add `ANTHROPIC_API_KEY`.
4. Click **Create Web Service**.

### A note about the free tier

Render's free web services spin down after 15 minutes of no traffic. The
first request after a quiet period takes 30–60 seconds while the server
wakes up; after that, responses are normal speed. If that cold-start delay
becomes a problem, the cheapest paid tier ($7/month) keeps the service
permanently warm.

## Running locally

Requires Node 18 or newer.

```bash
npm install
cp .env.example .env     # then edit .env and add your ANTHROPIC_API_KEY
npm start                # http://localhost:3000
```

## Project layout

| Path                          | Purpose                                              |
|-------------------------------|------------------------------------------------------|
| `index.html`, `style.css`, `app.js` | Frontend served as static files                |
| `server.js`                   | Express backend; exposes `POST /api/mark`            |
| `criteria/module-{a..h}.pdf`  | Official marking criteria, one PDF per module        |
| `assets/`                     | Logo and image assets                                |
| `package.json`                | Dependencies and npm scripts                         |
| `render.yaml`                 | Render Blueprint (one-click deploy config)           |
| `.env.example`                | Template showing which environment variables to set  |

## Environment variables

| Variable            | Required | Notes                                       |
|---------------------|----------|---------------------------------------------|
| `ANTHROPIC_API_KEY` | Yes      | Your Anthropic API key                      |
| `PORT`              | No       | Defaults to 3000. Render sets this for you. |
